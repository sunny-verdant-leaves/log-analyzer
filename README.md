# Log Analyzer

简单的自制日志分析器，支持插件扩展。

## 功能

- 选择日志文件夹，自动扫描 `.log` / `.txt` / `.out` / `.err` / `.debug` 文件
- 单日志查看（支持大文件截断，仅显示前 100KB）
- 多选日志批量分析
- 插件式分析方法，可加载外部 `.py` 插件
- 分析结果可导出为文本文件

## 内置插件

| 插件       | 说明                           |
| ---------- | ------------------------------ |
| 时间线分析 | 按时间维度分析日志事件分布     |
| 错误统计   | 统计日志中的错误类型和出现次数 |

## 运行

```bash
pip install flet
python main.py
```
